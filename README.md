# MailManager

Сервис управления email-рассылками на Django. Позволяет создавать получателей, сообщения и рассылки, отправлять письма по расписанию, отслеживать попытки и смотреть статистику.

## Возможности

- **Клиенты** — CRUD получателей рассылки (email, ФИО, комментарий)
- **Сообщения** — CRUD шаблонов писем (тема + тело)
- **Рассылки** — создание с указанием временного окна, выбором сообщения и получателей, ручная отправка
- **Попытки** — лог всех попыток отправки с статусом и ответом сервера
- **Статистика** — количество успешных, неуспешных и всего отправок
- **Роли** — обычный пользователь видит только свои объекты, менеджер — все
- **Кеширование** — главная страница и статистика кешируются через low-level cache
- **Динамический статус** — рассылки пересчитывают статус (Создана → Запущена → Завершена) по текущему времени



## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <url-репозитория>
cd MailManager_Project
```

### 2. Установить зависимости через Poetry

```bash
poetry install
```

### 3. Создать `.env` на основе `.env.example`

```bash
cp .env.example .env
```

Заполнить значения (минимум — `SECRET_KEY`).

### 4. Применить миграции

```bash
poetry run python manage.py makemigrations
poetry run python manage.py migrate
```

### 5. Создать суперпользователя

```bash
poetry run python manage.py createsuperuser
```

### 6. Запустить сервер

```bash
poetry run python manage.py runserver
```

Сервер доступен по адресу: http://127.0.0.1:8000/


### Создание менеджера

1. Зайди в админку: http://127.0.0.1:8000/admin/
2. Создай группу `Managers`
3. Создай пользователя и добавь его в группу `Managers`
